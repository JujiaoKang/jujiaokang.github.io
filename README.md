# Jujiao Kang Academic Homepage

## Pages

- `index.html` — Home
- `bio.html` — Bio
- `research.html` — Research
- `publications.html` — Publications
- `teaching.html` — Teaching
- `contact.html` — Contact

## How to preview

Double-click `index.html` to open it in a browser.

## How to add your photo

Put your portrait photo in the `assets/` folder and name it:

```text
profile.jpg
```

Then refresh `index.html`.

## How to deploy with GitHub Pages

1. Create a GitHub repository, for example `jujiaokang.github.io`.
2. Upload all files in this folder to the repository.
3. Go to repository `Settings` → `Pages`.
4. Choose the main branch as the publishing source.
5. Open the generated GitHub Pages URL.

## How to edit

- Update text content directly in the corresponding `.html` file.
- Update colors, spacing, and layout in `style.css`.
- Add more pages by copying one existing page and editing the navigation.
