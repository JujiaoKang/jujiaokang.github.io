# 学习通与非参数统计实验室的接入说明

## 已确认可采用的方式

**方案A：在《非参数统计》课程中添加实验链接（推荐先做）。**

1. 上传本目录完整静态网站到 GitHub Pages：`nonparam-lab/`。
2. 在学习通/泛雅《非参数统计》课程的“资料”或相应章节中使用“添加网址 / 网页链接”入口。
3. 链接名称填写“临床疗效评价与统计推断”，网址填写网站部署后的实际地址，例如 `https://jujiaokang.github.io/nonparam-lab/clinical-lab.html`（上传成功后自行测试）。
4. 用学生账号在学习通中打开，验证页面显示和本地报告下载。不同客户端可能会在内置浏览器或外部浏览器打开；以实际测试为准。
5. 学生在实验完成后从网页导出研究记录 JSON，提交至学习通作业；教师使用本网站“实验记录”页面导入和汇总。

此方案不需要模型API，也不自动同步学习通成绩；只是将实验教学入口接入课程。

**方案B：第三方链接创建课程智能体 / AI应用（如校内权限已开通）。**

教师平台“AI智能体”管理中部分版本有“创建AI智能体 → 第三方链接创建”；或在“AI应用”中使用“创建应用→填写链接”。可引用已经部署的实验网页。请以当前账号实际可见功能为准，必要时联系学校超星管理员。

此操作是**把外部网页放入学习通**，不等于**让GitHub网页调用学习通自己的问答模型**。

## 课程智能体可怎样配合本实验

- 在学习通AI助教知识库上传《非参数统计》课程教学大纲、教师本人制作的课件与实验指导书；课程资料授权与隐私需符合要求。
- 围绕5个实验阶段建立问答：数据分布、三组独立样本Kruskal–Wallis、两两比较与Holm校正、置换检验、错误填零、失访、Bootstrap、混杂与伪重复。
- 在学习通提供答疑、资料推荐和报告修改建议；在独立实验网页中负责生成数据、运行检验、记录实验操作。
- 先让学生导出实验报告后在学习通提交；是否支持一键上传、登录单点集成、成绩自动回传，应由校方与超星技术支持确认接口。

## 需要校方确认、不能擅自宣称已接入的能力

1. 教师课程是否开通“第三方链接创建”及学生使用权限。
2. 智能体是否有针对外部网页的官方API、SDK或可嵌入入口。
3. 是否支持校园统一身份认证 / LTI / 成绩回传，并有哪些安全要求。
4. 对接“实验空间”国家平台的要求是否另需建设独立系统；学习通课程链接不能替代等保、软著、国平台接口证明。

目前本站并**未**调用学习通智能体API，也**未**实现自动同步学习通成绩。
