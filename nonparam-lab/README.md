# 非参数统计实验室 v0.8｜问题驱动研究版

## 运行方式

本版本为纯前端静态网站，适合部署到 GitHub Pages。它使用可重复的模拟数据，不接收真实患者数据。

- `index.html`：网站首页。第一屏直接提出“三种康复方案，哪一种值得推广？”
- `clinical-lab.html`：新版五个研究问题驱动的综合实验；22项可记录操作，100分过程评价。
- `teacher.html`：本机实验记录、班级 JSON 批量导入、分问题成绩、操作证据与教师复核。
- `labs/spearman-rank-lab.html`、`labs/spearman-null-lab.html`：之前开发的两个 Spearman 专题实验。
- `advanced-lab.html`：保留 v0.7 的原25步工作台、策略对照、研究决策和统计助教。新版已不再以它作为主实验页面。
- `evaluation.html`：v0.7 原课程知识库检索评测页面。
- `assets/stats.js`：原统计模拟与检验引擎（沿用原版）；`assets/case.js`、`case.css`：新问题驱动流程。

## 新版五个研究问题

1. **哪一种方案看起来效果最好？** 描述统计、结局定义、图形探索、初步判断（4项、15分）。
2. **观察到的差异只是偶然吗？** 方法选择、Kruskal–Wallis、统计判断、两两检验和 Holm 校正、置换检验（5项、25分）。
3. **为什么改变条件，结论会不同？** 样本量、效应大小、误差分布、重复抽样、200次模拟估计拒绝率（5项、25分）。
4. **失访与分组偏差会误导我们吗？** 分组策略、缺失机制、不同缺失处理、伪重复反例（4项、15分）。
5. **证据足够支持推广吗？** Bootstrap百分位区间、缺失敏感性分析、研究建议、报告导出（4项、20分）。

流程自由切换，不要求逐题线性完成。内部计分依据实际操作产生的结果而非页面浏览。数据重新生成后，之前队列相关的记录仍保留为历史学习证据，但会标记“待复核”。最后的研究报告应以当前队列的证据为主，并对待复核项目重新核查。

## GitHub Pages 部署

1. 下载并解压部署 ZIP。
2. 在 `jujiaokang.github.io` 仓库中新建或进入 `nonparam-lab/` 文件夹。
3. 将压缩包根目录的 HTML 文件、`assets/`、`labs/` 等一并上传到该文件夹，**保留文件夹层级**；不要把它们放进另一个同名子文件夹。
4. 提交后预期地址为 `https://jujiaokang.github.io/nonparam-lab/`，实际访问以 GitHub Pages 发布结果为准。
5. 如果旧网页仍显示，请进行强制刷新或清除浏览器缓存。

**注意：** v0.8 是独立前端，不需要部署 Worker 即可完成五个问题；原 v0.7 在线大模型对接仍属于单独的进阶功能，必须通过后端保护模型密钥。不要将 API Key 放入 GitHub Pages。

## 学生与教师使用

学生：在综合实验右上角填写不含姓名等敏感信息的实验编号，自主完成操作，最后下载研究记录 JSON 和研究报告 TXT。重新抽样不会删除此前操作证据，但数据相关操作被标记“待复核”。

教师：在“实验记录”页面检查本机结果，也可以选择多个学生提交的 v0.8 JSON 文件，逐人查看22项操作记录、论证文本、历史队列标记，填写复核意见并导出班级 CSV。文件处理只在本机浏览器进行；本地复核意见关闭页面后不保证保留，请及时导出。

## 范围与限制

- 所有受试者资料均为模拟生成；模拟效应不是临床证据。
- 大样本 Kruskal–Wallis 与 Mann–Whitney 使用近似 P 值；极端小样本和并列秩需谨慎。
- 置换检验的交换性依赖研究设计，按病情分组场景仅作教学演示。
- 200次模拟估计拒绝率，结果有蒙特卡洛误差。模拟已强制固定区组随机、零失访以单独考察显著性水平及功效，不是所有临床条件下的推广结果。
- LOCF、BOCF是特定情景假设；“错误填零”和伪重复仅作为错误对照，不能用于有效临床推断。
- Bootstrap为分组中位数差的探索性百分位区间。
- 100分是自动过程分；是否正确提出科学论证需要教师审阅。不将自动评分等同于国家项目审核通过。
- 浏览器本地存储不具备账户、学校统一认证、云端成绩同步、等保测评或国家平台正式数据接口功能。这些需要后续单独建设与合规审核。

## 测试

开发目录包含 `tests/smoke_case.py` 浏览器测试脚本，覆盖五个问题的22项操作、JSON导出、教师端读取与复核和手机端布局。脚本为开发验证，不需要放到线上网站。
