## 2. 本版已经完成什么

- 首页、综合实验与专题实验统一导航；原有两个Spearman网页可从首页打开。
- 一个完整教学情境：三种数字康复方案比较，设置**25个教学交互任务**；每步4分，100分形成性评价。
- 学生可以改变随机化策略（包括有偏分组示例）、每组样本量、组间效应、误差分布、失访机制/比例、随机种子，并实际重新生成受试者数据。
- 生成模拟的基线、第2周、第4周疼痛评分、失访、依从性等；动态显示三组基线均值、改善量分布、失访人数和箱线图。
- 真正计算Kruskal–Wallis H（χ²(2)近似、并列秩校正）、Mann–Whitney U（正态近似、并列秩和连续性校正）、Holm调整、配对Wilcoxon、符号检验、Spearman相关（置换近似）、Bootstrap百分位区间和一种缺失压力情景。
- 任务判定、启发式提示、本地成绩记录与个人实验报告、记录JSON、成绩CSV导出。
- 手机、电脑自适应页面和离线的基本页面运行。

**教学步骤与立项要求的关系：** 目前是25项互动学习任务，其中包括问题识别、方法选择、模拟计算与研究解释。主管部门所称的“至少20步实质性实验交互操作”可能不把普通单项选择题全部计入；正式申报前还需由教学及技术团队把相应研究决策改造为可实际影响数据与操作反馈的交互，逐项对照规范核定。不能只以“25题”代替20步实质性操作的验收。

## 3. 本版**尚未完成**什么

1. **尚未接入真实大模型。** 当前“教学智能提示”明确是本地规则＋课程知识库的原型；没有调用任何外部AI API。正式接入大模型须由学校服务器转发，不能把密钥写在GitHub Pages公开HTML/JS中。
2. **尚无跨设备教师后台和正式账号。** `teacher.html`只能读取同一浏览器的`localStorage`，无数据库、班级管理、权限体系或统一身份认证。浏览器清缓存可能丢记录。
3. **尚未做等保二级、独立软件著作权登记、国家“实验空间”接口对接和压力测试。** GitHub Pages静态托管并不天然满足这些条件。
4. **尚未取得真实产业单位对接证明、真实患者数据或实际教学应用证明。** 本原型使用合成受试者及明确的模拟机制，绝无临床疗效证据。
5. 完整的实验指导书、教师操作手册、教学视频、无障碍与正式教学评价研究、真实生产环境运维还需要继续完善。

## 6. 从原型到正式系统的建设建议

### 第一阶段：2026年课程试用与教学逻辑验证
- 核验25项任务与课程目标的映射，明确**至少20个真正影响模拟状态、统计决策或结果反馈的实质性操作**，录制示范流程。
- 用R或SciPy逐项验证统计函数（处理小样本、并列秩、组别不等样本量）；完成专家审阅。
- 收集教师试用意见，进行小规模课堂体验，不虚报正式服务人数。

### 第二阶段：校内正式教学系统
- 后端：统一身份认证、数据库、成绩上传/导出、教师班级/实验管理、操作日志与题目版本化。
- AI：学校后端代理的大模型＋审校知识库，关键统计结果仍由统计引擎计算；建立可追溯答案及安全过滤。
- 运维：正式服务器、安全测试、平台所需的等保和接口联通；澄清软件著作权归属并办理材料。

### 第三阶段：每年新增一个行业完整情境
- 2027：工业质量控制（分布比较、排列检验、异常值与质量波动）。
- 2028：农业试验（区组／重复测量背景下的秩检验与稳健推断）。
- 2029：社会调查（有序响应、列联表与Spearman相关）。
- 2030：多学科案例、开放推广与教学评价验证。

## 7. 统计学范围和重要限制

- 核心结局是有界整数型的疼痛评分变化，容易存在并列值，方法结果采用相应校正或明确近似标注。
- Kruskal–Wallis检验的是分布相等，不可无条件等同于中位数相等；Mann–Whitney也不可无条件解释为中位数差。
- 配对Wilcoxon对位置变化的解释依赖差值对称性；本原型同时计算符号检验用于辅助比较。
- Spearman相关在本原型采用499次置换求双侧近似P值，并使用`(极端次数+1)/(B+1)`。
- Bootstrap百分位区间为演示性、探索性结果，不保证在所有离散分布和较小样本下具有良好覆盖率。
- 本原型只将“失访者不改善”作为压力情景，不能等同于临床数据缺失的合法、充分插补方案。
- 原有Spearman精确零分布页面的适用条件（无并列秩、独立随机观测）以页面自身说明为准；它与临床情境中可能产生并列分数的数据不能不加说明地直接混用。
